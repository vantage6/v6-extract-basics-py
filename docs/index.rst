v6-extract-basics-py
==================

Description
-----------

This algorithm makes the extraction functions defined in the vantage6 algorithm tools
available in an algorithm image. This documentation is kept minimal, as the extraction
functions are maintained in the general vantage6 repository, and documenting them here
would be redundant and difficult to maintain.

The extraction functions imported in this algorithms are available
`here <https://github.com/vantage6/vantage6/blob/main/vantage6-algorithm-tools/vantage6/algorithm/data_extraction/__init__.py>`_.
